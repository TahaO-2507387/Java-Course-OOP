# Java Course OOP

This repository is purely to make the daily assignments of our Advanced Object Oriented Programming course.
The assignments will be split into folders of each day and each folder will have a backlog containing how much time I spent for each exercise.

<br>

LLM usage will be minimal and primarily be done AFTER I make an exercise to get another point of view.
The usage of an LLM will be mainly to correct myself and learn more. Not to generate answers.
